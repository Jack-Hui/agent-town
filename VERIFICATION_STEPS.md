                    🆘 常见问题

═══════════════════════════════════════════════════════════════════

问题1: houses 表为空
解决: 
  $ npx convex run testing:resetWorld
  $ npx convex run init

问题2: ownerAgentId 为空
解决:
  先检查 agents 表是否为空
  如果为空，重新运行 init

问题3: 看不到时间字段
解决:
  检查 worlds 表的 JSON 是否包含 time 对象
  如果不包含，resetWorld 后重新 init
